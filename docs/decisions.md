# 待确认的决定

用户不在时按推荐方案先做了的决定，醒来后逐条确认即可（不同意的话告诉我改哪条）。

| # | 决定 | 理由 / 备注 |
|---|---|---|
| 1 | 投 vs 打击同帧：**打击优先**（投方被打中则投失效） | 不同作品规则不同，已集中在 `Combat.resolve`，改一处即可 |
| 2 | 双方同帧互投 → 双方进入拆投 | 常见做法 |
| 3 | 拆投窗口 7 帧，硬直结束后 3 帧投无敌，起身全程无敌 | 参考值，`CommonStates` 顶部常量 |
| 4 | 削血可以削死 | SF6 只有超杀削死，后续可做成规则开关 |
| 5 | 空中被打一律"浮空"，落地按是否击倒决定倒地或站起（空中重置） | M3 会加 juggle 点数限制追打 |
| 6 | 指令识别：方向回中（5）不打断搓招，"前走 → 回中 → 236" 可能出升龙 | 与街霸实际表现一致（"误出升龙"）；如需更严格可缩短 `Motion.max_gap` |
| 7 | 招式数据用 GDScript 数据表（`characters/shared/standard_moveset.gd`）而不是 .tres | 可读性和 diff 更好；以后做编辑器插件时再转格式 |
| 8 | 三个占位角色暂时共用同一套招式/帧数据，只有外观不同 | 先把系统做完，角色差异化放后面 |
| 9 | 公共状态目前直接引用 `CommonStates`（街霸风），还没有"规则模块切换"接口 | 第二套规则（GG/KOF 风）出现时再抽象，避免过早设计 |
| 10 | 拆投判定在被投方的更新里执行，P1/P2 的处理顺序会让"拆投后攻击方进入拆投状态"晚 0~1 帧 | 影响极小，回滚时仍确定 |
