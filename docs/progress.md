# 进度记录

## 2026-10-16
- **M1**：确定性仿真循环、整数物理、存读档、白模渲染、走/蹲/跳/推挤/摄像机墙。
- **像素占位素材**：`tools/spritegen/` 程序化骨骼 + 部件绘制，赛璐璐三阶阴影 + 有色描边。
  三个原创角色 Kagura / Volk / Mio，各两套配色；目前有 idle / walk_f / walk_b / crouch / prejump / jump / land。
  游戏内 2× 最近邻放大，F7 切换精灵/白模，F8/F9 切换角色。
- `tools/screenshot.gd`：用脚本输入推进仿真后截图，用于自查画面。
- **M2 核心**：
  - 状态数据化：`StateDef`（帧时间轴：判定盒、受击盒、速度事件、无敌、投）+ `Moveset`（公共状态 + 角色招式 + 出招表）。
    状态在运行时是整数索引，可哈希、可存档。
  - 输入：64 帧输入历史（进存档）；`Motion` 声明式指令识别（236/214/623 含捷径/236236/66/44），
    按当前朝向解释；按键缓冲 4 帧；出招表顺序即优先级（升龙优先于波动）。
  - 战斗：`Combat` 先收集后结算（投 vs 投 → 拆投；投方被打 → 投失效；打 vs 打 → 相打）；
    上中下段防御、近距离防御、削血（可削死）、顿帧、版边击退反推攻击方、浮空/击倒/起身（起身无敌）、KO。
  - 投与拆投（7 帧窗口）、硬直后 3 帧投无敌；飞行道具（耐久、互相抵消、同屏 1 个）。
  - 标准招式表：站/蹲各 6 普攻（帧数据按"发生/持续/收招/命中有利/防御有利"书写）、空中 6 普攻（上段）、
    波动（三种速度）、升龙（1~6 帧无敌）、突进踢、投。
  - 测试改为 `tests/run_all.gd` 自动发现；39 项测试，含每个地面普攻的命中/防御有利帧与数据完全一致的校验。
- **M2 精灵姿势**：生成器新增 18 个普攻、波动/升龙/突进踢/投、受击/防御/浮空/倒地/起身姿势，
  攻击动画固定三帧（发生/持续/收招），显示层按状态阶段选帧，与帧数据解耦；新增波动特效精灵（各角色配色）。
- 待确认的决定见 [decisions.md](decisions.md)。
- **M3 取消 / 连段 / 打康**：
  - 取消窗口：招式接触对手（命中或被防）后、持续帧结束 3 帧内可取消；顿帧中按下的键也有效（缓冲 = 4 + 顿帧）。
    目标由数据声明：`special`/`super`（必杀取消）、具体状态名（连打 5LP/2LP/2LK、Target Combo 5MP>HP）。
    `where: "cancel"` 的指令只能从取消窗口里出（Target Combo 后续）。空挥不能取消。
  - 连段状态挂在被打方：击数、连段伤害、轻攻击起手标记、追打计数；恢复可行动即清零（天然只统计"真连"）。
  - 补正：第 1、2 击 100%，第 3 击起每击 -10%，轻攻击起手再 -10%，最低 10%。
  - 追打：HitDef 的 juggle_start / juggle_limit / juggle_add（SF4/5 式），普攻默认不能追打，升龙可以。
  - 打康：被打方处于发生/持续 → Counter（硬直 +2，伤害 ×1.2），收招或可惩罚状态 → Punish Counter（硬直 +4）；
    相打双方都是打康；HitDef 可指定打康时替换效果（5HK 打康浮空）；投收招中的对手伤害 ×1.7。
  - HUD 在攻击方一侧显示 COUNTER / PUNISH COUNTER 与连段数、伤害。53 项测试。
- **M4 资源 / 超杀 / 回合**：
  - 通用资源槽 `Gauges`：规则模块定义一组槽（上限、分格、开局值、回复、回复停顿、Burnout、是否跨回合保留）。
    街霸风：超杀槽 3 格（跨回合保留）+ Drive 6 格（自然回复、前走额外回复、被防削减、耗尽 Burnout）。
  - 获取：命中 / 被防（减半）/ 被打 / 出必杀；招式数据 `cost` 声明消耗，不够时指令按优先级落到下一条。
  - Burnout：不能用 Drive 招式、防御普攻也被削血、防御硬直 +4，回满解除。
  - EX 必杀（236PP / 623PP，消耗 2 格 Drive）、超必杀 Lv1（236236P，1 格超杀槽，超杀暂停 40 帧、
    1~12 帧无敌、补正保底 30%），突进踢可超杀取消。
  - 回合：开场（不能操作）→ 战斗（99 秒）→ KO / 时间到 → 三局两胜；同血或双 KO 双方各得一胜。
    自由模式（默认，测试用）/ 训练模式（不会死、恢复后回满、可资源常满）/ 对战模式，F10 切换。
  - HUD：体力、Drive、超杀槽、计时、胜场、回合提示、超杀暂停压暗。
  - 编译测试改为自动扫描全部脚本（之前漏掉了新加的 HUD 脚本）。68 项测试。
- **M5 训练工具**：
  - 帧计量条（`tools/training/frame_meter.gd`）：逐帧记录 待机/移动/发生/持续/收招/硬直/倒地，
    自动显示最近招式的发生帧、总帧数和攻防结束后的有利帧（只在发生接触时显示）；超杀暂停和双方同时顿帧不计入。

  - 输入历史（`input_log.gd`）：相同输入合并计帧。
  - 叠加层显示以上内容；Shift+F6 版边重置。工具都是纯逻辑类，有无头测试。76 项测试。
