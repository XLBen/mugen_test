# 对照 SF6 的自省与修改（2026-10-17）

先分三路体检（规则 / 仿真、表现 / 流程、角色内容），列出和《街头霸王 6》的差距，再分 10 个阶段修改，每个阶段单独测试、提交。
各条规则的具体数值见 [decisions.md](decisions.md) 第 3、5、11、13、17、33–39 条。

## 体检结论

底层是扎实的：确定性整数仿真、存读档、打康 / 确反、SF6 式补正、OD、Burnout、逐帧判定、连段挑战与演示。
差距集中在 SF6 的"手感核心"和游戏外壳：

| 方向 | 修改前 |
|---|---|
| Drive 系统 | 只有 OD 和 Burnout；没有招架、完美招架、Drive Impact、Drive Reversal |
| 受击反应 | 只有一种倒地；没有崩溃、撞墙、硬 / 软倒地、后滚；确反没有额外顿帧、不扣 Drive；拆投不能预输入 |
| 角色内容 | 体力不统一；Kagura 有 SF6 没有的通用 Gatling、被防有利过多；没有指令普攻、目标连段、后投；升龙只有一种；超杀只有 1 格且偏痛 |
| 表现 | 镜头不缩放、超杀没有特写、KO 没有慢动作；打康只有小字；体力条没有红色延迟；P2 永远画在上层；影子是一条线 |
| 流程 | 只有训练场景；没有标题、选人、电脑对手；比赛结束后卡住 |

## 做了什么

| 阶段 | 内容 |
|---|---|
| 1 规则细节 | 确反额外顿帧并削 Drive；拆投预输入、晚按投也算拆投；起身投无敌；全员体力 10000 |
| 2 受击反应 | 崩溃、贴墙 / 弹墙（每连段一次）、按招式的倒地时长、后滚起身与硬倒地、眩晕；新状态的动画回退 |
| 3 Drive Impact / Reversal | 发生 26、两次霸体、命中崩溃 / 角落贴墙、Burnout 墙边眩晕；防御中 6HP+HK 无敌反击 |
| 4 Drive Parry | 按住招架、持续消耗、完美招架停顿 + 反击减半、招架被投算确反 |
| 5 角色内容 | 目标连段、指令普攻（6MP 中段 / 4HP 对空 / 6HK 远踢）、升龙 L/M/H、后投、轻攻击连打统一、Kagura 有利帧收紧 |
| 6 超杀等级 | SA1 / SA2 / SA3 与 Critical Art，伤害归一到 SF6 量级 |
| 7 表现 | 镜头缩放与超杀特写、KO 慢动作、SF6 式横幅、红色延迟扣血、攻击方在前、影子、Drive 系统特效与音效 |
| 8 流程 | 标题 → 选人 → 对局，暂停 / 结算菜单、重赛，P2 非小键盘按键 |
| 9 电脑对手 | 带反应延迟的效用式 AI，1–8 级，对战电脑和训练假人"电脑"模式 |
| 10 补充 | 蓄力指令（引擎支持）、导入人物的超杀动画映射 |

## 仍然没做 / 有意不做

- **Drive Rush**：按用户决定不做（连段表因此没有绿冲路线）。
- **背景音乐、角色语音、播报**：没有素材，音效全部是程序合成的。
- **舞台美术**：仍是灰色网格。
- **按键自定义、选项菜单、手柄按键映射界面**。
- **联网 / 回滚**：仿真已经确定、可存读档，联网层没做。
- **数值核实**：招架消耗与回复、确反扣 Drive 的量、起身投无敌、后滚输入、蓄力时间等写成了命名常量，标为"未核实"。
- **内置占位角色**的新招式（招架、DI、崩溃、超杀等）借用已有动画，没有专门的姿势。
